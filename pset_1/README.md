# Bikes computational project

## Organization
- `bikes_model.py`: model primitives, costs, exact-quality tie rules, demand, analytical demand Jacobian, active-hull solver, and equilibrium verification.
- `solve_equilibria.py`: solves all `t=1,...,10` for `mu=-0.5,0,0.5` under Bertrand-Nash and under the `a2`-`b1` coordination assumption. Writes the six required assignment CSVs, market-share panel, and diagnostics.
- `question_iii.py`: produces the Bresnahan-style product-positioning figure for `t=1` and `t=10`.
- `plot_market_shares.py`: produces a clean market-share-over-time figure for a chosen `mu` and regime.
- `run_all.py`: master script; runs all computations and figures.
- `output/`: **all generated output** — six assignment CSVs, diagnostics, market-share panel, and PNG figures.
- `bikes_results.qmd`: minimal R-free Quarto example.

## Run everything

From this directory:

```bash
python run_all.py
```

All files generated by the scripts go into `output/`. There is no separate
`figures/` directory.

## Market-share plots

The master script produces the `mu=0` Bertrand and coordination figures. To
generate another case:

```bash
python plot_market_shares.py --case bertrand --mu -0.5
python plot_market_shares.py --case collusion --mu 0.5
```

The resulting PNGs are written directly to `output/`.

## Prices in the CSVs

Every product-period observation has a numeric `pjt`. A product that is
inactive on the upper envelope, or removed by the reduced-form entry rule,
receives a high numerical suppression price. Its market share is zero. Since
the FOC is flat in the price of a zero-demand inactive product, that high
price is not economically identified; the numerical value is retained in the
panel rather than replaced by a blank.

## Quarto

Keep the QMD in this directory. Figures can be included directly with normal
Markdown image syntax using paths such as `output/product_positioning.png`.
No R code is required.
